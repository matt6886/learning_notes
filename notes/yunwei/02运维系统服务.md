### 计算机网络设备

**集线器（HUB）**

集线器的英文又称为Hub。Hub是中心的意思，集线器的主要功能是对接收到的信号进行再生整形放大，以扩大网络的传输距离，同时把所有节点集中在以它为中心的节点上。

**交换机**

交换机是按照通信两端传输信息的需要，用人工或设备自动完成的方法，把要传输的信息送到符合要求的相应路由上的技术统称。广义的交换机就是一种在通信系统中完成信息交换功能的设备。其实是更先进的网桥，它除了具备网桥的功能外，还通过在节点或虚电路间创建临时逻辑连接，使得整个网络的带宽得到最大化的利用。通过交换机连接的网段内的每个节点，都可以使用网络上的全部带宽来进行通信，而不是各个节点共享带宽。

**路由器**

路由器是一种网络交换设备，它基于OSI第3层地址在网络间传递数据分组。路由器能做出决定为网络上的数据分组选择最佳传递路径。因为路由器是根据网络地址转发数据。路由器的日常是检查每一个进来的分组（第三层数据），为他们选择穿过网络的最佳路径，然后将他们交换到适当的出口。在大型网络中，路由器是最重要的通信调节设备。实际上，路由器可使任何种类的计算机与世界上任何其他地方的计算机进行通信。

**路由器和交换机区别**

1. 交换机工作在OSI第2层，路由器工作在第3层。交换机的工作原理相对较简单，而路由器具有更多智能的功能，如选择最佳路线。
2. 交换机利用物理地址来确定是否转发数据；路由器是使用IP地址，由网络管理员来分配的。
3. 传统的交换机智能分割冲突域，而无法分割广播域；而路由器可以分割广播域

**第三层交换机**

三层交换机就是具有部分路由器功能的交换机。三层交换机最重要的目的是加快大型局域网内部的数据交换，所具有的路由器也是为这个目的服务的，能做到一次路由，多次转发。它解决了局域网中网段划分之后，网段路由器必须依赖路由器进行管理的局面，解决来传统路由器低速、复杂所造成的网络瓶颈问题。

**三层交换机与路由器的区别**

1. 主要功能不同

三层交换机同时具备了数据交换和路由转发两种功能，但其**主要功能还是数据交换**；而路由器**仅具有路由转发这一项功能**。

2. 主要适用的环境不一致

三层交换机的路由功能通常比较简单，因为它所面对的**主要是简单的局域网连接**。路由器主要是**用于不同类型的网络之间**，他**最主要的功能就是路由转发**。所以路由器的路由功能通常非常强大。不仅适用于同种协议的局域网间，更适用于不同局域网和广域网之间。它的优势在于选择最佳路由，负荷分担，链路备份及和其他网络进行路由信息的交换等等路由器所具备功能。为了与各种类型的网络连接，路由器的接口功能非常丰富，而三层交换机则一般仅同类型的局域网接口，非常简单。

3. 性能体现不一样

三层交换机和路由器在数据包交换操作上存在明显的区别。路由器一般由基于微处理器的软件路由引擎执行数据包交换，而三层交换机通过硬件执行数据包交换。

三层交换机的性能要远优于路由器，非常适用于数据交换频繁的局域网中；而路由器虽然路由功能非常强大，但它的数据包转发效率要远低于三层交换机，更适用于数据交换不是很频繁的不同类型的网络互联，如局域网与广域网的互联。

**网关**

网关在传输层上以实现网络互联，是最复杂的网络互联设备，仅用于两个高层协议不同的网络互联。基本的功能是实现不同网络协议之间的转换。

| **备名称** | **OSI层** | **主要功能**       | **是否能识别MAC** | **是否能识别IP** | **典型场景**         |
| ---------- | --------- | ------------------ | ----------------- | ---------------- | -------------------- |
| 集线器     | 第1层     | 信号转发（广播）   | ❌                 | ❌                | 简单实验环境         |
| 二层交换机 | 第2层     | 根据MAC地址转发    | ✅                 | ❌                | 局域网通信           |
| 路由器     | 第3层     | 不同网络间路由转发 | ✅                 | ✅                | 内外网互联           |
| 三层交换机 | 第2+3层   | VLAN间高速路由     | ✅                 | ✅                | 企业内网核心         |
| 网关       | 各层      | 协议/网络类型转换  | ✅                 | ✅                | 网络出口、系统间通信 |

### 网络设备连接介质

**双绞线**

1. 双绞线一般用于星型网络的布线，每条双绞线通过两端连接的RJ-45连接线（俗称水晶头）将各种网络设备连接起来。用于主机到集线器或者交换机的连接。
2. 双绞线中有两种标准

* 568A标准：绿白-1，绿-2，橙白-3，蓝-4，蓝白-5，橙-6，棕白-7，棕-8
* 568B标准：橙白-1，橙-2，绿白-3，蓝-4，蓝白-5，绿-6，棕白-7，棕-8
* 直通线：双绞线两端是一样标准，如568B-568B（常用）
* 交叉线：双绞线两端标准不一样买入568A-568B

3. 网络设备连接

* 直通线：交换机到路由器、计算机到交换机、计算机到集线器等**不同设备**互联
* 交叉线：交换机到交换机、交换机到集线器、集线器到集线器、路由器到路由器、计算机到计算机、计算机到路由器等**相同设备**互联。

**光纤**

与其他传输介质比较，光纤的电磁绝缘性更好、信号衰减小、频带宽、传输速度快、传输距离大。主要用于要求传输距离长、布线条件特殊的主干网连接。具有不收外界电磁场的影响，无限制的带宽等特点，可以实现每秒方兆位的数据传输，尺寸小，重量轻，数据可传输几百千米，但价格昂贵。



### IP和MAC地址

**IP和MAC地址简介**

1. 以太网上的两台计算机之所以可以交换信息就是因为每台设备都有一个网卡，并且每个网卡拥有唯一的物理地址（成为MAC地址）和唯一的逻辑地址（称为IP地址）。
2. MAC地址是由生产厂商烧录好的，一般不能改动，并且全球唯一，IP地址需要绑定到网卡上，并且同一个IP地址不能绑定在多个网卡上。
3. MAC地址和IP地址区别如下

* MAC地址和IP地址的结构长度不一样

  * MAC地址是48位的16进制数，IPv4是32位的二进制数，IPv6地址是128位的，通常写成8组，每组位四个16进制数的形式
  * IPv4地址使用**点分十进制**法表示，IPv6使用**冒分十六进制**法表示

  > IPv4地址： 192.168.1.1
  >
  > IPv6地址：2001:0db8:85a3:0000:0000:8a2e:0370:7334
  >
  > MAC地址：00-E1-8C-D8-EC-EF

  * MAC地址和IP地址在OSI模型中寻址层不同
    * IP地址应用于OSI的第三层，即网络层
    * MAC地址应用在OSI的第二层，即数据链路层
  * MAC地址和IP地址的分配方式不一样
    * MAC地址分为前24位（称为组织唯一标识符，是由`IEEE`的注册管理机构分配给厂商分配）和后24位（称为扩展标识符，由厂商自己分配）
    * IP地址由网络拓扑结构决定分配



### IP地址介绍

**IP地址介绍**

* 为了便于根据iP地址寻找到该地址所代表的主机，这个32位的二进制数被分为两部分：**网络ID（网络号）**和 **主机ID（主机号）**
* 网络号：区分网络是否在同一个区段（网段），说明可以划分为几个网络或区域
* 主机号：区分同一个网络中的主机，说明网络里有多少台主机。

说明：我们现在所说的互联网就是两个或两个以上的网络进行互联。

**子网掩码介绍**

* 子网掩码不能单独存在，它必须结合IP地址一起使用
* 子网掩码只有一个作用，就是将某个IP地址划分为网络地址和主机地址两部分，用来判断两个IP是否在同一个网络
* 子网掩码是一个32的二进制数，用 **点分十进制数** 表示，其对应网络地址的所有位置都为1，对应主机地址的所有位置都为0

**IP地址分类**

| 分类 | 范围（公有IP）              | 私有IP                        | 网络范围 | 备注     |
| ---- | --------------------------- | ----------------------------- | -------- | -------- |
| A类  | 0.0.0.0 - 127.255.255.255   | 10.0.0.0 - 10.255.255.255     | 大规模   |          |
| B类  | 128.0.0.0 - 191.255.255.255 | 172.16.0.0 - 172.31.255.255   | 中等规模 |          |
| C类  | 192.0.0.0 - 223.255.255.255 | 192.168.0.0 - 192.168.255.255 | 小规模   |          |
| D类  | 224.0.0.0 - 239.255.255.255 |                               |          | 组播地址 |
| E类  | 240.0.0.0 - 247.255.255.255 |                               |          | 保留     |

> 补充：十进制转换二进制：除2取余，倒序排列，不够前面补0



### A类IP地址

* A类IP地址由1字节的网络地址和3字节的主机地址组成，网络地址的最高位必须为`0`
* 地址的表示范围为 `0.0.0.0 - 127.255.255.255`，默认子网掩码为 `255.255.255.0`或者 `/8`
* 网络号全部为0表示保留不能用
* 网络号全部为1的IP `127.X.X.X/8`表示保留，用于本机回环测试用
* 主机号全为0代表本主机所在的网络地址；主机号全为1代表网络上的所有主机，故不能分配

综上所述：

* A类地址可用的网络数为 2^7 - 2 =126
* A类地址每个网络可容纳的主机数为2^24 - 2 = 16,777,214 （上千万台）
* A类地址一般分配给规模比较大的网络使用



### B类IP地址

* B类IP地址由2个字节的网络地址和2个字节的主机地址组成，网络地址的最高位必须为`10`
* 地址范围为 `128.0.0.0 - 192.255.255.255`， 默认子网掩码为 `255.255.0.0` 或者 `/16`
* 网络号全部为0一般表示保留（老教材），现在可以用
* 主机号全为0代表本主机所在的网络地址；主机号全为1代表网络上的所有主机，故不能分配

综上所述：

* B类地址可以使用的网络数为2^14=16,384 个
* B类地址每个网络能让那的主机数为2^16-2=65,534 个（上万台）
* B类地址一般分配给中型网络使用



### 特殊IP

**C类IP地址**

* C类PI地址由3个字节的网络地址和1个字节的主机地址组成，网络地址的最高位必须为`110`
* 网络地址范围为 `192.0.0.0 - 223.266.255.255`，默认子网掩码为 `255.255.255.0`或者 `/24`
* 网络号全部为0一般表示保留（老教材），现在可以用
* 主机号全为0代表本主机所在的网络地址；主机号全为1代表网络上的所有主机，故不能分配

综上所述：

* C类地址可用的网络数为2^21=2,097,152 个
* C类地址每个网络能容纳的主机数为2^8-2=254 
* C类地址一般分配个小型网络使用

| 0.0.0.0         | 表示整个网络                           | 可表示本机源地址，可以表示某个特定主机    |

### 子网划分

**子网划分核心**

**借用**主机位来**制造**新的子网。

IP地址 = 网络号 + 主机号（子网位 + 主机位）

IP地址 = 网络位 + 子网位 + 主机位

**子网划分方法**

```bash
IP = 网络号 + 主机号
               |
     子网位（n） + 主机位（m）
假设子网位为n，主机位为m，则子网数为2^n个，主机数为2^m - 2个，
子网掩码都是由一窜连续的0或连续的1组成，这里可以将n看做后面有多少个1，m看做后面有多少个0，
由于主机位全0表示本网络，全1留作广播地址，减掉2
```

* 根据子网掩码判断主机数

```bash
11111111.11111111.11111000.00000000

2^11 - 2 =2,046 
```
